## 0. Rationale for Separate Crate

`RotamerLibrary` is a reusable building block (rotamer packing, design, repacking, any backbone-dependent placement) with no algorithmic coupling to ConFind's contact-degree logic. Keeping it inside `proxide-confind` would foreclose reuse and bloat that crate. A standalone `proxide-rotlib` has no dependency on other proxide crates, making it a true leaf and easy to audit independently.

## 2. On-Disk Binary Format

The MSL rotamer library is a **single binary file** (not a directory). Numeric fields are native-endian as written by C++ `fwrite` (little-endian on x86). Strings are null-terminated byte sequences. Float fields are `f32`; integer fields are `i32`. Coordinates are stored in the canonical backbone-relative frame (see §7).

**File structure — per amino acid, repeated until EOF:**

```
aa_name:  null-terminated string   (e.g., "ALA\0")
nc:       i32    — number of chi angles
na:       i32    — number of sidechain heavy atoms
nb:       i32    — number of phi/psi bins

[chi angle definitions — nc entries]
  for each chi:
    atom0, atom1, atom2, atom3: each a null-terminated string

[sidechain atom names — na entries]
  for each atom:
    atom_name: null-terminated string

[phi/psi bin descriptors — nb entries]
  for each bin:
    phi:       f32   (standard range [-180, 180) applied immediately after read)
    psi:       f32
    frequency: f32   (relative count; used only to identify default_bin)

[rotamer data — nb bins]
  for each bin b in 0..nb:
    nr: i32           — number of rotamers in bin b
    for each rotamer ri in 0..nr:
      prob:  f32
      for each chi in 0..nc:
        chi_value: f32
        chi_sigma:  f32
      for each atom in 0..na:
        x: f32
        y: f32
        z: f32        — atom position in canonical backbone-relative frame
```

EOF = file read fails (no amino-acid count header).

**`angle_to_standard`** — normalize to `[-180.0, 180.0)`. Apply to every phi/psi immediately after reading:

```rust
fn angle_to_standard(a: f64) -> f64 {
    let mut v = a.rem_euclid(360.0);
    if v >= 180.0 { v -= 360.0; }
    v
}
```

**Grid validation** after reading all nb bins for one AA:
- Extract sets of unique phi values and unique psi values.
- Require: `unique_phi.len() * unique_psi.len() == nb` (rectangular grid).
- Require: no duplicate `(phi, psi)` pairs.
- Fail with `RotlibError::InvalidFormat` on violation.

## 3. In-Memory Representation

```rust
pub struct RotamerLibrary {
    entries: HashMap<String, AaEntry>,
}

struct AaEntry {
    atom_names:      Vec<String>,    // na names, in library order
    bin_phi_centers: Vec<f64>,       // sorted unique phi (degrees f64), len = n_phi_bins
    bin_psi_centers: Vec<f64>,       // sorted unique psi (degrees f64), len = n_psi_bins
    // n_psi_bins = bin_psi_centers.len()  (needed for bin_index formula)
    default_bin:     u32,            // index of bin with highest frequency
    rotamers:        Vec<BinData>,   // len = nb, indexed by bin_index
}

struct BinData {
    probs:  Vec<f64>,                // len = nr; prob[ri]
    coords: Vec<Vec<[f64; 3]>>,     // [ri][atom_i] = xyz; upcast from f32 at load time
}
```

**`bin_phi_centers`/`bin_psi_centers`**: sort the unique phi/psi sets in ascending order; convert to `f64`.

**`default_bin`**: `argmax` over frequency values; first maximum wins on tie.

**`bin_index`** = `phi_ind * n_psi_bins + psi_ind` (phi-major, matching MSL line 405).

All `f32` coordinates and probabilities are upcast to `f64` at parse time. No `f32` inside the crate after `load()` returns.

## 4. Backbone Bin Lookup

```rust
impl RotamerLibrary {
    /// Map (phi, psi) in degrees to a linear bin index.
    /// 9999.0 sentinel (either angle) → default_bin.
    pub fn backbone_bin(&self, aa: &str, phi: f64, psi: f64) -> Result<u32, RotlibError>;
}
```

**Sentinel**: `if phi == 9999.0 || psi == 9999.0 { return Ok(entry.default_bin); }`

**`find_closest_angle`** — shortest-path circular distance, returns index:

```rust
fn find_closest_angle(centers: &[f64], query: f64) -> usize {
    centers.iter().enumerate()
        .min_by(|(_, &a), (_, &b)|
            angle_diff(a, query).total_cmp(&angle_diff(b, query)))
        .unwrap().0
}

fn angle_diff(a: f64, b: f64) -> f64 {
    let d = (a - b).abs() % 360.0;
    if d > 180.0 { 360.0 - d } else { d }
}
```

`total_cmp` avoids NaN panics in production; should never produce NaN on valid library data.

**Final**: `phi_ind * n_psi_bins + psi_ind` as `u32`.

### `RotamerId`

```rust
#[derive(Clone, Hash, Eq, PartialEq, Ord, PartialOrd, Debug)]
pub struct RotamerId {
    pub aa:        String,   // 3-letter AA code
    pub bin_index: u32,      // phi-major linear index
    pub rot_index: u32,      // 0-based within bin (0 = most probable)
}
```

`Ord` is lexicographic `(aa, bin_index, rot_index)` — used by `proxide-confind` for stable rotamer-pair accumulation order (see §9.5 of `260529_confind.md`).

### `PlacedRotamer`

```rust
pub struct PlacedRotamer {
    pub id:    RotamerId,
    /// All sidechain heavy atoms, in library atom order. Includes CB.
    /// Does NOT include backbone atoms N, CA, C, O.
    /// Caller (ConFind) is responsible for applying `counts_as_sidechain` filtering.
    pub atoms: Vec<PlacedAtom>,
}

pub struct PlacedAtom {
    pub name: String,
    pub xyz:  [f64; 3],
}
```

**CB semantics**: `place_rotamer` returns CB for all amino acids. ConFind's `cache_residue` applies `counts_as_sidechain` to exclude CB for non-ALA residues. The library does not pre-filter.

### Sidechain helper (also in `proxide-rotlib`, for ConFind and other callers)

```rust
/// True iff atom_name counts as sidechain in ConFind-style clash detection
/// (doNotCountCB=true: CB excluded for all AAs except ALA).
pub fn counts_as_sidechain(atom_name: &str, aa: &str) -> bool {
    if is_backbone_or_hydrogen(atom_name) { return false; }
    if atom_name == "CB" && aa != "ALA" { return false; }
    true
}

/// True for N, CA, C, O, H, and any name starting with 'H' (hydrogen).
pub fn is_backbone_or_hydrogen(name: &str) -> bool {
    matches!(name, "N" | "CA" | "C" | "O" | "H") || name.starts_with('H')
}
```

## 6. Frame and Transform (`src/frame.rs`)

Self-contained rigid-body types. No `nalgebra` dependency — plain `[[f64; 4]; 4]` matching MSL's homogeneous matrix layout.

```rust
/// Local coordinate frame defined by an origin and three orthonormal axes.
#[derive(Clone, Debug)]
pub struct Frame {
    pub origin: [f64; 3],
    pub x: [f64; 3],
    pub y: [f64; 3],
    pub z: [f64; 3],
}

impl Frame {
    /// Construct from raw (unnormalized) axis vectors. Normalizes all three.
    pub fn new(origin: [f64; 3], x_raw: [f64; 3], y_raw: [f64; 3], z_raw: [f64; 3]) -> Self;
    pub fn identity() -> Self;  // origin=[0,0,0], x=[1,0,0], y=[0,1,0], z=[0,0,1]
}

/// Homogeneous 4×4 rigid-body transform (row-major).
/// Layout: upper-left 3×3 = rotation R; right column rows 0–2 = translation t.
#[derive(Clone, Debug)]
pub struct Transform {
    m: [[f64; 4]; 4],
}

impl Transform {
    pub fn identity() -> Self;
    /// Apply transform to a 3D point: R*p + t.
    pub fn apply(&self, p: [f64; 3]) -> [f64; 3] {
        [0,1,2].map(|i|
            self.m[i][0]*p[0] + self.m[i][1]*p[1] + self.m[i][2]*p[2] + self.m[i][3])
    }
    /// Build transform that maps points from `from`-frame to `to`-frame.
    /// Matches `TransformFactory::switchFrames` (msttransforms.cpp lines 530–546).
    pub fn switch_frames(from: &Frame, to: &Frame) -> Self;
}
```

**`switch_frames` algorithm** (MSL lines 530–546):

```
T1 = 3×3 matrix, columns = [from.x | from.y | from.z]
T2 = 3×3 matrix, columns = [to.x   | to.y   | to.z  ]
ori = from.origin - to.origin
result = T2⁻¹ · translate(ori) · T1
```

For orthonormal T2, `T2⁻¹ = T2ᵀ`. The composed 4×4:
```
R_4x4 = T2ᵀ · T1      (3×3 upper-left)
t_4x4 = T2ᵀ · ori     (right column rows 0–2)
bottom row = [0, 0, 0, 1]
```

## 7. Rotamer Placement (`place_rotamer` internals)

**Backbone frame** (matches MSL `placeRotamer` lines 182–194):

```
x_raw = ca - n          // N→CA
z_raw = cross(x_raw, c - ca)    // (N→CA) × (CA→C)
y_raw = cross(z_raw, x_raw)
Frame::new(ca, x_raw, y_raw, z_raw)
```

**Placement**:

```rust
let bin = self.backbone_bin(aa, phi, psi)?;
let entry = &self.entries[aa];
let bin_data = &entry.rotamers[bin as usize];

let res_frame = backbone_frame(n, ca, c);
let lab_frame = Frame::identity();
let xform = Transform::switch_frames(&res_frame, &lab_frame);

let atoms = bin_data.coords[rot_index].iter()
    .zip(&entry.atom_names)
    .map(|(&xyz, name)| PlacedAtom { name: name.clone(), xyz: xform.apply(xyz) })
    .collect();

Ok(PlacedRotamer {
    id: RotamerId { aa: aa.to_string(), bin_index: bin, rot_index: rot_index as u32 },
    atoms,
})
```
